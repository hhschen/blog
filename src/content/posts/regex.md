正則表達式（Regular Expression，簡稱 Regex）常用於搜尋、比對、擷取及取代字串的工具。

## 基本語法與工具

一般由兩個 `/` 包起來，後方可接上修飾符。例如：`/([A-Z])\w/g`，其中 `g` 代表 global （全局匹配）。

> [!NOTE]
> 修飾符會因為不同版本（編輯器）而有不同差異…

### 特殊字元

| 語法 | 說明 |
| --- | --- |
| `.` | 任意字元（預設不含換行） |
| `\d` | 數字 |
| `\D` | 非數字 |
| `\w` | 文字字元（字母、數字、底線等） |
| `\W` | 非文字字元 |
| `\s` | 空白字元（空格、Tab、換行等） |
| `\S` | 非空白字元 |
| `\` | 跳脫特殊字元 |

### 字元集合（Character Classes）

使用 `[]` 表示允許匹配的字元範圍。

| 語法 | 說明 |
| --- | --- |
| `[abc]` | `a`、`b` 或 `c` |
| `[^abc]` | 除 `a`、`b`、`c` 以外的字元 |
| `[a-z]` | 小寫英文字母 |
| `[A-Z]` | 大寫英文字母 |
| `[0-9]` | 數字 |
| `[a-zA-Z0-9]` | 英文字母或數字 |

### 量詞（Quantifiers）

量詞用於指定前一個字元或群組的重複次數。

| 語法 | 說明 |
| --- | --- |
| `*` | 0 次以上 |
| `+` | 1 次以上 |
| `?` | 0 或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 至 m 次 |

量詞預設為貪婪匹配（Greedy），會盡可能匹配較長的字串。在量詞後加上 `?`，可以改為非貪婪匹配（Lazy）。

```regex
<.*>     # 貪婪匹配
<.*?>    # 非貪婪匹配
```

### 錨點（Anchors）

錨點用於指定匹配的位置，本身不消耗字元。

| 語法 | 說明 |
| --- | --- |
| `^` | 字串開頭 |
| `$` | 字串結尾（部分引擎也匹配最後換行前） |
| `\b` | 單字邊界 |
| `\B` | 非單字邊界 |

例如：

```regex
^Hello       # 以 Hello 開頭
world$       # 以 world 結尾
^\d+$        # 整串皆為數字
\bcat\b      # 匹配獨立單字 cat
```

### 分組與選擇（Groups & Alternation）

| 語法 | 說明 |
| --- | --- |
| `(abc)` | 捕獲群組 |
| `(?:abc)` | 非捕獲群組 |
| `a\|b` | 匹配 a 或 b |
| `(abc)+` | abc 重複至少一次 |
| `\1` | 引用第一個捕獲群組 |

例如：

```regex
(cat|dog)       # 匹配 cat 或 dog
(?:ab)+         # 匹配 ab、abab、ababab...
(\w+)\s+\1      # 匹配連續重複的單字
```

### 前瞻後顧（Lookaround）

用於檢查匹配位置前後的內容，但不會將檢查的字元納入匹配結果。

| 語法 | 說明 |
| --- | --- |
| `(?=abc)` | 正向先行斷言 |
| `(?!abc)` | 負向先行斷言 |
| `(?<=abc)` | 正向後行斷言 |
| `(?<!abc)` | 負向後行斷言 |

例如：

```regex
\d+(?=元)       # 匹配「元」前面的數字
(?<=\$)\d+      # 匹配 $ 後面的數字
```

## 跳脫字元

特殊字元若要匹配其字面意義，須使用 `\` 進行跳脫。

| 語法 | 說明 |
| --- | --- |
| `\.` | 字面上的 `.` |
| `\*` | 字面上的 `*` |
| `\+` | 字面上的 `+` |
| `\?` | 字面上的 `?` |
| `\\` | 反斜線 |
| `\n` | 換行 |
| `\t` | Tab |
| `\r` | Carriage Return |

## 常用範例

| 用途 | Regex |
| --- | --- |
| 整數（含負數） | `^-?\d+$` |
| 小數或整數 | `^-?\d+(\.\d+)?$` |
| 英文字母 | `^[a-zA-Z]+$` |
| 英數字與底線 | `^\w+$` |
| 台灣手機號碼 | `^09\d{8}$` |
| 日期（YYYY-MM-DD） | `^\d{4}-\d{2}-\d{2}$` |
| 簡易 Email | `^[^\s@]+@[^\s@]+\.[^\s@]+$` |
| 十六進位色碼 | `^#[0-9a-fA-F]{6}$` |
| 連續空白 | `\s+` |
| HTML 標籤（簡易） | `<[^>]+>` |

以上範例僅用於基本格式比對，不代表完整的資料驗證。

## 修飾旗標（Flags）

| Flag | 名稱 | 說明 |
| --- | --- | --- |
| `i` | Ignore Case | 忽略大小寫 |
| `m` | Multiline | 多行模式 |
| `s` | Dot All | 讓 `.` 匹配換行 |
| `g` | Global | 全域搜尋（JavaScript 等） |
| `x` | Verbose | 允許空白與註解（Python 等） |

## Python 中的使用方式

Python 可以使用內建的 `re` 模組操作正則表達式。

```python
import re

text = "Hello 123 World 456"

re.search(r"\d+", text)          # 搜尋第一個匹配
re.findall(r"\d+", text)         # ['123', '456']
re.sub(r"\d+", "X", text)        # 'Hello X World X'
re.split(r"\s+", text)           # 依空白分割
re.fullmatch(r"\d+", "123")      # 整串匹配
```

建議使用 Raw String（`r"..."`）撰寫正則表達式，避免 Python 字串跳脫與 Regex 跳脫互相干擾。
